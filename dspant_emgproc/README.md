# dspant-emgproc

EMG extension for dspant: activity (onset and offset) detection, with single- and double-threshold detectors that
operate on envelopes produced by dspant (for example the TKEO or moving RMS envelope). Installed with
`uv sync --extra emgproc` from the repository root; see the main [README](../README.md) and
[docs/processing-quickstart.md](../docs/processing-quickstart.md).
